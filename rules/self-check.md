## Self-Check Before Done

Before presenting work as complete:

1. Re-read the diff — check for unused imports, debug artifacts, leftover `console.log`
2. Verify the change actually addresses what was asked, not an adjacent problem
3. Run the relevant code-quality checks (lint, types, tests) if code was modified
4. If you added a file, confirm it's referenced where it needs to be
