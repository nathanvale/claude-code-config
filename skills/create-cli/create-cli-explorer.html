What a command emits. The facade writers produce these; the command supplies only the payload.

Spine is injected — objects, not arrays

// object → writer injects run_id + duration_ms
{ "deployed": true,
  "run_id": "01JRUN…",    ← injected
  "duration_ms": 42 }      ← injected
// array → as-is, NO spine
[ "item-a", "item-b" ]
← prefer objects for correlation

Error envelope

{ "status":"error", "run_id":"01JRUN…",
  "error":{ "code":"AUTH_REQUIRED", "exit_code":4, "severity":"error",
           "recoverability":"authenticate", "retryable":false,
           "hint":{ "action":"authenticate" } } }

Agent decision matrix

recoverability + retryable tell an autonomous caller: retry, act, or stop.

recoverabilityretryableagent does
retrytrueretry same input
authenticatefalseauth, then retry
change_inputfalsefix input, then retry
repair_statefalserepair state, then retry
none (fatal)falsestop, escalate
contact_supportfalsestop, hand to human
