What a command actually emits. The facade writers produce these; the command supplies only the payload.

The observability spine is injected — for objects, not arrays

// object payload → writer injects run_id + duration_ms
{
  "deployed": true,
  "run_id": "01JRUN…",      ← injected
  "duration_ms": 42         ← injected
}
// array payload → written as-is, NO spine
[
  "item-a",
  "item-b"
]  ← no correlation; prefer objects

The agent decision matrix — what the agent does next

severity, recoverability, and retryable are independent. They tell an autonomous caller whether to retry, act, or stop.

recoverabilityretryableagent does
retrytrueretry the same input (after any backoff)
authenticatefalserun auth flow, then retry
change_inputfalsefix the input, then retry
repair_statefalserepair local state (clear cache…), then retry
none (often fatal)falsestop — do not retry; escalate
contact_supportfalsestop — hand to a human
