# ADHD Helper Context

This context owns durable language for ADHD-shaped executive-function support in the `adhd-helper` skill.

## Language

**Moment Map**:
The user-state vocabulary that decides which kind of executive-function support fits the request.
_Avoid_: mode router, prompt selector, routing contract

**Support Card**:
A reusable support shape that teaches how to respond to one executive-function moment without becoming a deterministic output contract.
_Avoid_: prompt card, prompt body, schema, recipe
