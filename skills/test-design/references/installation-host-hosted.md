# Installation, Host, and Hosted Systems

- Generated or packaged output does not prove installation, discovery, activation, trust, host UI, or hosted delivery.
- Use a fresh isolated install or profile for first-discovery claims.
- Bind evidence to the exact revision, package, or release being qualified.
- Distinguish local canaries, live-host canaries, and hosted checks in the handback.
- Fail visibly when a required host is unavailable; do not silently convert the case into a lower-layer test.
- Keep live credentials and raw host evidence outside source and snapshots.
