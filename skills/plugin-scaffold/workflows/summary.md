# Workflow: Summary

## Goal

Summarize what was scaffolded and what the plugin author still needs to customize.

## Summary format

Report:

- plugin name
- chosen tier
- generated files
- ownership model selected
- any delegated or external contracts that still need plugin-specific wording
- reminder to align the plugin README and smoke checks with the new setup surface

## Success criteria

- the user can see the generated file tree
- the remaining customization points are explicit
