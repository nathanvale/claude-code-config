Does snapshot-first search earn its complexity?

This demo tests whether parent-filtered snapshot and app tools beat context-free agents without hiding useful session candidates.

Measured locally on 11 Aug 2026. No transcripts or session identifiers are embedded. Warm, frozen cold, and parent app-source lanes were exercised.

Current verdict: keep every session-search lane in the parent. Parent snapshot search matched agent candidates with fewer calls. Parent cold refresh completed in 129 ms while the agent failed twice. Parent app filtering exposed a 110-token summary; isolated agents lacked the app tool.
