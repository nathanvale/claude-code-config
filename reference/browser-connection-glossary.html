Browser connection glossary

One sentence per layer. Read top to bottom.

Chrome 150
The browser process: pages, cookies, profiles, DevTools, and current Chrome security behavior.
CDP
The JSON command/event protocol tools use to inspect and control Chrome.
CDP endpoint
A loopback HTTP/WebSocket address exposed by Chrome when launched with a remote-debugging port.
Warm Chrome
A real, persistent Chrome session plus proof that a tool is attaching to the intended binary, profile, and endpoint.
Adapter
A client translating its own commands into browser operations, such as agent-browser, Playwright, or Chrome DevTools MCP.
Auto-connect
An adapter-specific discovery or permission handshake that finds a running Chrome without requiring the caller to supply a stable CDP endpoint.
UI auto-connect
Chrome 144+ consent flow used by supported clients to reach the active Chrome session without legacy HTTP discovery.
Channel discovery
An adapter looks in Chrome's known profile location for the active DevTools connection instead of receiving a port from the caller.
Explicit CDP
The caller supplies an HTTP or WebSocket endpoint; this is the most widely supported adapter contract.
Extension attachment
An installed Chrome extension attaches to selected tabs through chrome.debugger, a restricted CDP transport that needs no public port.
WebDriver
A browser automation standard commonly used by Selenium; ChromeDriver usually creates or manages the browser session.
WebDriver BiDi
A bidirectional cross-browser automation protocol; it is not the CDP endpoint shared by Chrome-specific adapters.
Target
A debuggable Chrome object such as a tab, iframe, worker, or browser; target ownership prevents multi-agent collisions.
In-app Browser
A Codex-owned browser-control surface; useful inside Codex, but not a generic endpoint other tools can consume.
Firefox
A separate browser lineage with its own automation connection; it does not attach to Chrome.
Rule of thumb: Chrome is the browser, CDP is the language, Warm Chrome is the verified session, and adapters are the speakers.
