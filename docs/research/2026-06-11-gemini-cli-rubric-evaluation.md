# Gemini CLI Rubric Evaluation

Use this evaluation as the fourth filled example for `docs/research/2026-06-11-agent-cli-evaluation-rubric.md`.

## Tool

- Name: Gemini CLI.
- Installed command: `gemini`.
- Version: `0.45.0`.
- Installed path: `/opt/homebrew/bin/gemini`.
- Public surface: mixed human and agent CLI.
- Source: `https://github.com/google-gemini/gemini-cli/tree/v0.45.0`.
- Local source used for structure: `/tmp/gemini-cli-v0.45.0-agent-cli-eval`.

## Invocation Chain

- `/opt/homebrew/bin/gemini`.
- Symlink to `/opt/homebrew/Cellar/gemini-cli/0.45.0/bin/gemini`.
- Node script handles memory sizing and relaunch.
- Relaunched Node process imports bundled runtime.
- Runtime parser and command handlers run in the same JS package.

## Classification

- Public command surface: Mixed human CLI and agent-native CLI.
- Hidden or internal machine seams: ACP, stream-json events, MCP client plumbing, and internal slash-command services.
- Installed wrapper chain: Homebrew symlink to bundled Node runtime.
- Source architecture: TypeScript monorepo with separate CLI, core, ACP, commands, services, policies, tools, and integration tests.

## Scores

- Wrapper: `1`.
- Command contract: `1`.
- Protocol seams: `2`.
- Discovery and registry: `1`.
- Repair and recovery: `1`.
- Observability: `2`.
- Folder structure and ownership: `2`.

Total: `10 / 14`.

Interpretation:

- Strong agent-facing runtime.
- Strong headless JSON and streaming JSON path.
- Strong ACP seam.
- Discovery commands are useful but mostly human text.
- Public subcommands are not consistently covered by JSON output.
- Wrapper is centralized, but not a thin wrapper in the Playwright/Codex pattern.

## Evidence

### Wrapper

- `gemini --version` returns `0.45.0` with exit `0`.
- `/opt/homebrew/bin/gemini` is a symlink to the Homebrew package script.
- The script:
  - reads `~/.gemini/settings.json` for memory behavior
  - computes Node memory flags
  - relaunches the CLI process unless disabled
  - forwards stdio
  - preserves child exit code
  - imports the bundled runtime when relaunch is disabled or complete
- The wrapper does not duplicate parser behavior.
- The wrapper is more than a locator/argv forwarder.

Score: `1`.

Reason:

- Behavior is centralized.
- Wrapper is not boring-thin because relaunch, memory sizing, cleanup, and runtime loading are mixed into the installed entry script.

### Command Contract

- Top-level help is generated by `yargs`.
- Public subcommands include:
  - `mcp`
  - `extensions`
  - `skills`
  - `hooks`
  - `gemma`
- Parser and help share yargs metadata.
- Command handlers are separated under `packages/cli/src/commands/`.
- No `discover --json` or full command catalog was found.
- `--output-format json` belongs to the default prompt command.
- `gemini --output-format json mcp list` fails with `Unknown arguments: output-format, outputFormat`.
- `gemini --output-format json skills list` fails the same way.

Score: `1`.

Reason:

- Help and parser share metadata.
- Agents still need help text and source knowledge for subcommand discovery.
- Machine output does not cover the whole command tree.

### Protocol Seams

- `gemini -p <prompt> --output-format json` is documented for structured output.
- `gemini -p <prompt> --output-format stream-json` is documented for JSON event streaming.
- `nonInteractiveCli.ts` emits stream events with:
  - event type
  - timestamp
  - session id
  - model
- `--acp` starts Agent Client Protocol mode.
- ACP source lives under `packages/cli/src/acp/`.
- MCP support is public through `gemini mcp`.
- Source has MCP client and prompt loader owners under CLI and core packages.

Score: `2`.

Reason:

- Machine seams are explicit and public.
- ACP and stream-json are agent-useful without scraping TUI output.

### Discovery And Registry

- `gemini mcp list` reports configured MCP servers.
- `gemini skills list` reports discovered skills, status, descriptions, and locations.
- `gemini --list-extensions` exits cleanly; no extensions produced no output in this environment.
- `gemini --list-sessions` reports stored sessions for the current project.
- `--output-format json` did not apply to `mcp list`, `skills list`, or `--list-sessions` in tested runs.
- Skills discovery in an untrusted folder reports trust gating before listing user skills.

Score: `1`.

Reason:

- Discovery exists and is productized.
- Discovery output is mostly human text.
- Registry state lacks a uniform parseable catalog.

### Repair And Recovery

- Unknown prompt-like input in an untrusted folder returned a clear trust error.
- The trust error named repair paths:
  - `--skip-trust`
  - `GEMINI_CLI_TRUST_WORKSPACE=true`
  - trust the directory in interactive mode
  - read the trusted-folders docs
- Parser validation catches mutually exclusive prompt/session flags.
- Invalid `--output-format` values fail before runtime.
- Parser failures are human text.
- No uniform failure envelope was found with retry safety, side-effect state, diagnostics pointer, and next action id.

Score: `1`.

Reason:

- Human recovery guidance is good.
- Recovery is not yet a structured agent contract.

### Observability

- `--debug` is public.
- `--output-format stream-json` emits parseable runtime events.
- Stream init includes session id and model.
- `--session-id`, `--resume`, `--session-file`, `--list-sessions`, and `--delete-session` are public.
- Non-interactive output handles cancellation and EPIPE.
- Source includes telemetry, startup profiler, cleanup, and debug logger surfaces.
- No top-level run correlation id was observed for ordinary subcommands.

Score: `2`.

Reason:

- The headless runtime has strong event observability.
- Session handling is first-class.
- The gap is command-tree-wide consistency.

### Folder Structure And Ownership

- CLI parser and runtime:
  - `packages/cli/src/config/config.ts`
  - `packages/cli/src/gemini.tsx`
  - `packages/cli/src/nonInteractiveCli.ts`
- Public commands:
  - `packages/cli/src/commands/`
- ACP:
  - `packages/cli/src/acp/`
- Slash command services:
  - `packages/cli/src/services/`
  - `packages/cli/src/ui/commands/`
- Core runtime:
  - `packages/core/src/`
- Policy:
  - `packages/core/src/policy/`
- Integration tests:
  - `integration-tests/`
- Evals:
  - `evals/`

Score: `2`.

Reason:

- Ownership boundaries are easy to find.
- CLI, protocol, command, policy, core, tests, and evals have visible homes.

## Copy

- Offer both `json` and `stream-json` for headless runs.
- Make session id user-controllable for reproducible automation.
- Expose ACP as a public protocol mode.
- Gate untrusted folders with concrete repair paths.

## Avoid

- Do not let global machine-output flags silently apply only to one branch of the command tree.
- Do not make registry discovery agent-useful but human-text-only.
- Do not mix wrapper duties with runtime startup more than needed.

## Candidate Decisions

- Machine-output flags should either apply command-tree-wide or fail with a command-specific explanation.
- Agent CLIs should expose protocol mode and event stream mode as separate public seams.
- Trust errors should name exact non-interactive repair paths.

## Unresolved

- Check whether newer Gemini CLI releases add JSON output for `mcp`, `skills`, sessions, or command discovery.
- Check whether ACP command registry could become public command metadata.
