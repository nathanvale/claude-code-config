Nested Loop Hierarchies

Mission loops spawn goal loops, which spawn agent loops, which spawn workflow loops, which run tool loops.

Mechanism
Five-Level Loop Hierarchy
Mission loop (perpetual)
unbounded — scans for new work
↓
Goal loop (per objective)
terminates when objective is met
↓
Agent loop (per agent)
terminates when agent scope is exhausted
↓
Workflow loop (per task)
terminates when task is done
↓
Tool loop (per action)
terminates when action completes
⏹ Each level terminates when its scope is exhausted; mission loop is unbounded

The Pattern

Complex agentic systems aren't a single loop — they're a hierarchy of loops, each operating at a different scope. @NathanWilbanks_ built a five-level architecture: mission → goal → agent → workflow → tool.

The insight is that each level of the hierarchy has a different time horizon and a different stop condition. Tool loops terminate when the action completes. Workflow loops terminate when the task is done. Agent loops terminate when the agent's scope is exhausted. Goal loops terminate when the objective is met. The mission loop never terminates — it keeps scanning for new work.

Why nested hierarchies matter

A flat loop (one level, one stop condition) breaks down at scale. When you have hundreds of concurrent agents working toward a shared mission, you need a coordination layer above them. The mission loop is the scheduler; the goal loop is the project manager; the agent loop is the worker.

The perpetual mission loop

The mission loop reads from external sources (GitHub issues, a task queue, Slack messages) to find the next goal. It's unbounded — it runs as long as the system is alive. This is the Boris Cherny model: "My job is to write loops." The mission loop is the thing that makes the agent fleet self-directing.

# Conceptual sketch
while True:  # mission loop — perpetual
    goal = mission_loop.next_goal(github, slack, queue)
    
    for task in goal_loop.decompose(goal):  # goal loop
        agent = agent_loop.assign(task)      # agent loop
        
        for step in workflow_loop.plan(task):  # workflow loop
            tool_loop.execute(step)             # tool loop

TL;DR

Decompose agent systems into five loop levels — mission, goal, agent, workflow, tool — each with its own stop condition. The mission loop is perpetual and self-directing; every level below it is scoped and bounded. This hierarchy scales to hundreds of concurrent agents without losing coordination.
