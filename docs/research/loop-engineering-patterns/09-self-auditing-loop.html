The Self-Auditing Loop

An agent reads its own instruction set and surfaces contradictions. The loop corrects itself.

Cycle Mechanism

TL;DR

Point an agent at its own configuration files. Ask it to find contradictions between rules. Feed the contradiction list back into the instruction set. Terminate when no new contradictions appear in a full audit pass — not when the total contradiction count hits zero.

How It Works

Point agent at instruction repo
→
Agent reads all instruction files
→
Agent surfaces internal contradictions
→
Contradictions feed correction loop
→
Updated instructions re-read on next run
↺ loops back to start on next run
Stop: No new contradictions found in a full audit pass

In Practice

The self-auditing loop points an agent at its own configuration — CLAUDE.md files, AGENTS.md, skills, rules — and asks it to find contradictions, gaps, or conflicts. The audit output feeds directly back into the instruction set, closing the loop.

@PawelHuryn's experience with Fable 5 reveals why this matters: agent instruction sets accumulate over time, and contradictions creep in. Rule A in one file conflicts with Rule B in another. A human writing new rules doesn't always check for conflicts with existing ones. An agent auditing the instruction set has no such blind spot.

The contradiction-as-signal pattern

The audit agent doesn't just read — it reasons about consistency. "Rule X says always do A. Rule Y says never do A in context Z. These conflict when..." The output is a list of specific contradictions with their context, not a vague report about quality.

Why this is harder than it looks

@Prathkum's critique applies here too: loops need context of what changed. A self-auditing loop that runs on a schedule without tracking which rules changed since the last audit will re-surface the same contradictions repeatedly — a while(true) that burns tokens. The stop condition must be: new contradictions since last run = 0.

# Loop terminates when
audit_result.new_contradictions_since_last_run == 0

# Not when
audit_result.total_contradictions == 0  # this never converges
