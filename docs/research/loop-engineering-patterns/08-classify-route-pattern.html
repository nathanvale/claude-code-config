Classify-and-Route

One agent reads the input, decides the category, the script routes it to the right specialist.

Cycle Mechanism

TL;DR

Separate classification from execution. A cheap classifier agent returns a category; deterministic code routes to the right specialist. Never let the classifier also do the work.

How it works

Loop Flow
Input arrives
→
Classifier agent reads + decides type
→
Script routes to specialist
→
Specialist executes
→
Output returned or re-classified
↺ re-classify if output does not pass validation
STOP: Specialist completes and output passes validation

Pattern deep-dive

The classify-and-route pattern separates the decision about what to do from the execution of doing it. A classifier agent reads the input and returns a category; the harness (not another agent) routes to the right specialist based on that category.

This is fundamentally different from asking one agent to "figure it out and do it." The classifier is cheap and fast. The specialist is focused and accurate. The routing logic is deterministic code — not LLM inference.

Why the routing must be code

If you let the classifier also do the routing (e.g. "decide what to do and then do it"), you get a general-purpose agent that is mediocre at everything. The routing step — reading the classifier output and dispatching the right specialist — should be explicit code. This makes it inspectable, testable, and deterministic.

classification = classifier_agent.classify(input)

match classification.type:
    case "bug_report":     specialist = bug_fixer_agent
    case "feature_request": specialist = planner_agent  
    case "docs_question":  specialist = docs_agent
    case _:                specialist = triage_agent

result = specialist.execute(input, classification.context)

The unattended failure mode

@akshay_pachaar's observation applies directly here: a loop running unattended is also a loop failing unattended. The classify-and-route pattern makes failures visible — when the classifier returns an unexpected category, the match falls through to triage and you get a clear signal. Bad classifications don't silently propagate to wrong specialists.
