ADHD Helper Prompt Pack

How to convert ten reusable executive-function prompts into a repo-owned skill without turning the skill into a prompt dump.

Date: 2026-06-15 Topic: adhd-helper-prompt-pack Mode: repo-grounded Raw ideas: 42 Survivors: 7

Grounding Context

Codebase Context

  • skills/adhd-helper/SKILL.md already exists as an untracked main-entry skill.
  • Current modes: Start, Unstick, Triage, Resume, Reduce, Reset.
  • Current response shape favors short bullets, next action first, time boxes, and no moral language.
  • Repo rules keep skills thin, move depth into one-level references, and keep contracts in owner paths.

Prompt Inventory

The X post's ten roles are useful labels: Get Me Started, Turn Chaos Into a Plan, Body Double Mode, Dopamine-Friendly Work Plan, Finish the Thing, Anti-Procrastination Reframe, Task Translator, Decision Helper, Overwhelm Reset, and 4-Hour Deep Work Sprint.

The raw prompt text is source material, not a contract.

Past Learning

  • Prompt bodies belong in references or templates, not startup instructions or a bloated skill entry.
  • Examples teach judgment; they do not own schemas or allowed values.
  • The parked ADHD hook work found useful closeout and mission framing, but rejected noisy hooks, rigid mission state, control tokens, and fragile JSON.

External Context

  • Public ADHD prompt lists cluster around initiation, prioritization, time-blocking, brain dumps, resets, routines, distraction handling, and accountability.
  • The differentiator is routing the right support at the right moment.
  • Safety risks: medical boundary drift, crisis handling, over-reliance, planning as avoidance, cognitive overload, and privacy.

I1.

Mode Router With Prompt Cards

Conf 93%Cx Medium
Description
Keep the existing six ADHD Helper modes as the canonical router. Convert the ten prompt roles into source-attributed prompt cards that map onto those modes by user moment: starting, sorting, deciding, co-working, finishing, resetting, or sprinting.
Axis
Pattern inventory and mode mapping.
Basis
direct: adhd-helper already has six modes; repo rules favor one workflow per skill, thin skill bodies, one-level references, and examples over abstract explanation. external: ADHD prompt lists cluster by executive-function moment, so routing beats copying.
Rationale
This is the highest-leverage conversion. It preserves the current skill shape, makes the X prompt names discoverable, and gives future prompt packs a place to land without rewriting the router.
Downsides
The card shape needs discipline. If each card grows into a full prompt body plus schema, the reference becomes a second bloated skill.
I2.

Planning Fuse

Conf 90%Cx Low
Description
Add a reference-level rule for any big-plan prompt: sort or plan only until the next visible action is possible, then stop. Use this for Turn Chaos Into a Plan, 4-Hour Deep Work Sprint, Anti-Procrastination Reframe, and any request that risks becoming planning-as-avoidance.
Axis
Response shape and low-cognitive-load examples.
Basis
direct: current ADHD Helper puts the chosen next action first and ends with one visible action, not a full system. external: external grounding flags planning-as-avoidance and cognitive overload as core risks.
Rationale
This prevents the skill from becoming a prettier procrastination machine. It makes every planning card answer the same question: what can start now?
Downsides
Some users genuinely need a longer plan. The rule needs an escape hatch: expand after a first action, explicit user request, or known deadline.
I3.

Relay Baton Continuation Card

Conf 88%Cx Low
Description
End the relevant modes with a tiny continuation baton: objective, mode, blocker, next visible action, timer, stop condition, and re-entry cue. Keep it in the response by default; persist it only through an explicit handoff.
Axis
Handoffs and continuations.
Basis
direct: the current response example already uses next action, mode, blocker, timer, and stop condition. The parked ADHD hook notes found closeout useful but rejected noisy lifecycle machinery.
Rationale
Context loss is a named trigger for the skill. A baton gives a future agent or future self enough state to restart without adding hidden memory.
Downsides
If always printed, the baton may become clutter. Use it for resume, body double, finish, reset, and sprint flows, not every tiny start.
I4.

Safety Acuity And Handoff Matrix

Conf 88%Cx Medium
Description
Give every prompt card the same safety triage: green for next-action support, amber for privacy/durable-memory/external-action risk, red for clinical, medication, crisis, or self-harm route-out. Add a handoff matrix for task capture, music/body-doubling ambience, durable context, and external actions.
Axis
Safety and privacy boundaries.
Basis
direct: current ADHD Helper already routes clinical, medication, crisis, and self-harm requests to qualified help; it stops before external state changes and durable private context unless explicitly asked.
Rationale
This lets the skill stay useful without becoming a mental-health service, a hidden memory writer, or an automation trigger.
Downsides
The color model can become policy theater if copied into every card. Better: one matrix reference, cards cite it.
I5.

Stateless Body Double Loop

Conf 84%Cx Medium
Description
Convert Body Double Mode into an opt-in chat loop: declare task, pick a touch point, run 8-25 minutes, return with done/blocker/next, choose continue/stop. Avoid hooks, background nudges, mission tokens, and durable state.
Axis
Handoffs and continuations.
Basis
direct: archived ADHD hook work rejected noise, rigid missions, control tokens, and fragile state while preserving session boundaries and closeout as useful. external: body-doubling and Pomodoro patterns support declared intent plus timed check-ins.
Rationale
This keeps the accountability benefit while matching the repo's lower-noise, user-initiated skill style.
Downsides
Chat check-ins are weaker than real human body doubling. The skill needs honest framing: support loop, not replacement accountability.
I6.

Tone Calibration And Anti-Examples

Conf 84%Cx Low
Description
Add a compact examples reference that translates moralizing, therapy-ish, diagnosis-y, or over-planning responses into neutral next-action language. Treat Anti-Procrastination Reframe as a response pass that names friction plainly and returns one reversible move.
Axis
Response shape and low-cognitive-load examples.
Basis
direct: the current skill bans moral language, blame, and productivity theater. ADR 0010 says examples may teach judgment but not own contracts.
Rationale
Tone is part of safety. A few before/after examples likely improve every card more than more abstract instruction.
Downsides
Too many anti-examples can make the reference feel scolding. Keep them tiny and task-family specific.
I7.

Decision And Task Translator Gate

Conf 80%Cx Medium
Description
Fold Decision Helper and Task Translator into one gate for ambiguous work: objective, working input, output owner, missing input, reversible default, and first action. Link the create-skill input/output gate as the owner path when the work is skill or agent-tool shaped.
Axis
Skill boundary and owner paths.
Basis
direct: current ADHD Helper already offers 2-4 choices when deciding, asks at most one question, and chooses a next safe action when low-risk. The create-skill runbook already owns input/output gate vocabulary.
Rationale
This bridges personal executive-function support with agent-native work. It helps the user move without giving the skill hidden authority over external actions or durable writes.
Downsides
It risks pulling create-skill mechanics into ADHD Helper. Keep exact create-skill contracts in the owner path, and use only the shape.
