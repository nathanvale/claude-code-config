# Repo Rules For LLMs

This repository is Nathan's personal control plane and synthesis hub.

## Memory OS Integration

- Shared user-scope contract: `~/.config/memory/AGENTS.md`
- Repo profile: `life-hub`
- This repo owns personal control-plane context, deep recall memory in `memory/`, authored notes in `docs/`, promoted durable knowledge, and federated recall entrypoints.
- Do not treat this repo as a dump of every external repo. Promote selectively.
- `CLAUDE.md` is the hot cache, `memory/` is compact durable recall, and `docs/` is for full authored documents.
- Do not use PARA folders as the primary storage model in this repo.
- Prefer QMD for broad federated recall and use NotebookLM with curated source packs for higher-order artifacts such as briefings, podcasts, and infographics.
