Browser Stack Map

One-page reference · claude-code-config · compressed from lesson 0001

The assembly line

warm-chrome

Proves the browser is really Agent Chrome. Emits ok envelope or exit 20.

→

browser-connect

Runs the proof in-process, injects the verified endpoint, probes the adapter.

→

Verified Handoff Envelope

The only artifact that crosses the seam.

→

browser-use

Discovers targets, authorizes and runs operations. Never finds Chrome.

→

mcporter → adapter

MCP protocol client speaking to chrome-devtools-mcp, which drives Chrome over CDP.

Command cheat sheet

CommandDoes
browser-connect check [--json]Read-only proof of Agent Chrome; exit 20 on failure with a station + repair path
browser-connect connect <adapter> --jsonProve + attach + mint the envelope
browser-connect run <adapter> -- <cmd>Same guarantee, then exec the tool (human path)
browser-use targets list --handoff <file> --jsonDiscover pages through the attached adapter

Glossary

Agent Chrome / Human Chrome
The dedicated automation Chrome with explicit CDP (provided by warm-chrome) vs Nathan's everyday Chrome — never an attachment target. runtime/browser-connect/CONTEXT.md
Warm Chrome
The reusable authenticated browser environment; Agent Chrome and Warm Chrome name the same browser from two sides. skills/browser-use/CONTEXT.md
Browser Adapter
A tool that attaches to a proven browser via a declared route. Adapters never find Chrome themselves. runtime/browser-connect/CONTEXT.md
Verified Handoff Envelope
Success direction: a proven connection handed forward. Evidence to act on, not permission to guess. runtime/browser-connect/CONTEXT.md
Browser Entry Handoff
Failure direction: an unready browser environment handed back to browser-use for recovery. The envelope's deliberate mirror — never conflate them. skills/browser-use/CONTEXT.md
Proof chain
warm-chrome's single verification path every command shares: loopback, listener identity, profile posture, CDP round-trips. runtime/warm-chrome/CONTEXT.md
Station
One deterministic agent-visible command outcome (id = error code = action), pinned by tests. Sixteen in warm-chrome. runtime/warm-chrome/CONTEXT.md
Repair Path
The complete recovery contract every error station ships: stable action id, typed context, one continuation posture, versioned REPAIR.md anchor. runtime/browser-connect/CONTEXT.md
Endpoint authority
The ok envelope is the only source of endpoints; consumers take them verbatim, never from the 9222 convention. runtime/warm-chrome/CONTEXT.md
Exit 20
Browser-entry proof failed; adapter fallback and cold browsers are forbidden as continuations. runtime/warm-chrome/CONTEXT.md
handoff-bound
The discovery mode whose binding evidence is the envelope (formerly route-bound, Router era). skills/browser-use/CONTEXT.md
mcporter
A general MCP protocol client CLI. In this stack it is hired plumbing: it speaks initialize/tools-call over stdio to the adapter. It owns no browser policy.
